About ROCOv2 (critical — corrects the original whiteboard)
ROCOv2 images come from the PMC Open Access Subset, ~79,789 images.
UMLS CUIs are already included per image, extracted via MedCAT (trained on MIMIC-III) — no live UMLS API call or license needed for training data.
Implication: the "Bio/UMLS → CUI" lookup step on the whiteboard is unnecessary at training time. The real design problem is predicting CUIs from the image at inference (since ground-truth CUIs won't be available then).

Research Gap Identified

No reviewed paper combines (1) predicting CUIs from ROCOv2 images, (2) explicitly fusing predicted-CUI embeddings with visual features via a named mechanism, and (3) decoding a full report — evaluated with BLEU-1–4 and ablated against a no-concept baseline, all in one system on ROCOv2. That combination is the project's defensible contribution.

"Hybrid" — precise definition adopted

NOT a CNN ensemble (already done by others, not novel). Instead: one CNN backbone + one concept-prediction sub-network, fused via cross-attention — this is Candidate B from three options considered (A: ensemble — rejected as unoriginal; B: single CNN + concept branch — recommended; C: multi-scale single-CNN taps — good future ablation, not v1).

UMLS/CUI Pipeline (final algorithm)
Training: ROCOv2's built-in CUIs → multi-label targets → BCE loss trains the concept head. This is the only place ground truth CUIs are used.
Inference: image → concept head → top-k predicted CUIs → embedding lookup → fusion. Reference report/CUIs never touched.
CUI encoding: a learned embedding table (nn.Embedding), not BioBERT — no reviewed paper uses BioBERT to encode CUI codes specifically (BioBERT fits free text, not discrete concept IDs).
Report Decoder Choice

Transformer decoder recommended over CNN+LSTM/GRU — parallelizable, matches nearly all recent papers reviewed, integrates naturally with cross-attention into the fused memory.

Teacher forcing during training (feed ground-truth previous token).
Autoregressive generation at inference (feed model's own previous prediction) — watch for exposure bias.
Padding mask + causal mask needed.
Vocabulary built from ROCOv2 captions directly, ~2,000–5,000 tokens for the prototype.
Loss Function (starting values, not final-tuned)
Total Loss = α × Report Generation Loss (cross-entropy, label smoothing 0.1)
           + β × Concept Loss (BCE on concept-head logits)

α = 1.0, β = 0.5   (starting point — tune based on Phase 3/4 validation behavior)
